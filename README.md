## 快速开始

### 1. 克隆项目

> 本项目包含 Git 子模块，克隆后需要初始化并下载子模块。

```bash
# 克隆主仓库
git clone https://github.com/hc2088/test-flutter-mix.git
cd test-flutter-mix

# 初始化并拉取子模块
git submodule update --init --recursive




也可以用一条命令直接克隆主仓库和子模块：
git clone --recursive https://github.com/hc2088/test-flutter-mix.git
